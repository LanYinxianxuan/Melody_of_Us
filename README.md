# Melody AI —— 情感 AI 聊天

一个纯前端的 AI 数字人应用：**38 维情感状态机 · 剧情系统 · 时间系统 · 多存档 · 角色创建向导**。

## 快速开始

```sh
npm install
npm run dev
```

打开 http://localhost:5173/playground/home.html

> 首次进入会弹出**角色创建向导**：选预设（仁菜 Nina / 小鲸）或自定义（写一段介绍，AI 访谈追问生成角色卡）。
> 聊天功能需要 DeepSeek API Key（菜单页设置，`deepseek-v4-flash`）。

## 构建与部署（手机自己跑）

```sh
npm run build    # 生成 dist/ 纯静态文件（含 PWA：manifest/sw/图标）
```

把 `dist/` 目录部署到任意静态托管（GitHub Pages / Netlify / Vercel / 云服务器 Nginx 等）。
部署后手机浏览器打开 URL → **添加到主屏幕** = 全屏 App，之后离线也能打开（PWA 缓存），不再依赖电脑。

移动端已适配：小屏聊天页面板变抽屉、刘海屏安全区、触控字号。

## 页面

| 页面 | 说明 |
|---|---|
| `home.html` | 首页 |
| `menu.html` | 菜单：5 个独立存档（情感/剧情/时间线/角色各自独立）+ 设置 + 清空数据 |
| `chat.html` | 主玩法：情感聊天 |

## 核心系统

- **38 维情感**：人格(5) / 关系(6) / 情绪(12) / 状态(5) / 阴影(10)，每轮 delta 变化 + 惯性回归
- **剧情**：按天归档（Day Journal）、剧情线（开了头要推进/了结）、随机事件（对话流旁白）、多人对话（AI 自行应变扮演第三方）
- **时间**：真实时钟同步、可调速率（0.01×~100000×）、手动跳转、起始日期、相遇时刻开局
- **在场**：校内面对面 / 校外手机消息（📱）
- **角色**：预设 + 自定义（AI 访谈追问）+ 随时修改
- **存档**：5 槽位独立，菜单管理

## 架构（模块化）

```
playground/
├── state.ts      情感状态机（维度/delta/回归/描述）
├── storage.ts    数据层（多存档槽位/持久化）
├── character.ts  角色档案（预设/存取）
├── time.ts       时间系统（时钟/速率/作息/在场）
├── story.ts      剧情系统（阶段/档案/剧情线/随机事件）
├── ai.ts         DeepSeek 集成（聊天/容错解析/演示/访谈）
├── wizard.ts     角色创建向导（介绍 + AI 访谈）
├── chat.ts       UI/流程层（渲染/消息/胶水回调）
└── menu.ts       菜单页（存档列表/设置）
```

跨模块通信用回调注入（`setMessageSender` 等），依赖单向无循环。

## 说明

- 数据全部存浏览器 localStorage（多槽位），无后端
- DeepSeek 请求经 vite 代理 `/api/chat`（避免 CORS）
- 演示模式（🎭）免 Key 可体验完整链路
