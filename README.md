# 『与你共鸣的日子』Melody_of_Us
----
## 简介
《与你共鸣的日子》Melody_of_Us 是基于《girls band cry》设定的同人二创文字互动游戏（gag/game 风格）。游戏侧重于角色日常与情感线，通过对话和选择推进剧情，体验校园生活与人际关系的变化。本作为非商业粉丝作品，旨在探索角色互动与分支结局的可能性。

## 游戏特色
- 多条剧情分支与数个结局，选择会影响人物好感与后续走向。  
- 以日常互动与聊天为主，加入少量小游戏与事件判定。  
- AI 驱动的对话系统扮演 nina，使每次游玩都有不同表达与反应。  
- 轻量化网页与安卓双平台支持，便于随时体验。

## 玩法
1. 支持浏览器或安卓端下载游玩，保持网络可选以启用云存档和 AI 聊天功能。  
2. 你扮演一名初中生，开学分班时幸运地成为 nina 的同桌，随后展开日常互动。  
3. 通过对话选择、活动参与与赠送物品等方式提升与角色的好感度，解锁支线剧情。  
4. 游戏包含主要剧情线、友情线与恋爱线（如适用），以及若干隐藏结局。  
5. AI 扮演 nina，角色回复会根据好感和剧情状态动态生成，请注意保存进度。

## 角色
- Nina：与你关系密切的同桌，性格设定与行为会随剧情变化。  
- 同班同学们：若干可互动 NPC，提供支线任务与信息。  
- 导师/家长等配角：推动剧情并影响玩家选择的社会背景。

## 安装与运行
- 浏览器：打开项目主页或本地 HTML 文件，建议使用最新版本的 Chrome/Firefox。  
- 安卓：下载 APK 并允许未知来源安装（仅在受信任来源下载时进行）。  
- 建议备份存档，开启网络功能可同步云端数据。

## 存档与多周目
- 支持手动与自动存档，多周目可继承/重置特定数据以探索不同结局。  
- 推荐在关键选择前手动保存以便回溯。
